✦ Codelab 2 — Calculate a Custom Tip
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Objective
  Extend the Tip Time app so the user can enter a custom tip
  percentage, and optionally round up the tip.

Final Features
  • Bill Amount text field with $ icon
  • Tip Percentage text field with % icon
  • Keyboard action buttons: Next → Done
  • Round up tip? switch (rounds tip to nearest dollar)
  • Vertical scroll (landscape support)

New Concepts Learned
  • Passing a label as a @StringRes parameter
  • @DrawableRes and leading icons in TextField
  • KeyboardOptions with imeAction (Next/Done)
  • Switch composable
  • Boolean state + conditional calculation
  • verticalScroll + rememberScrollState

Reference
